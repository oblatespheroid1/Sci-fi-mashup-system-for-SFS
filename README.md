# Sci-fi-mashup-system-for-SFS
An SFS planet pack with planets and stars that are a mix of real planets and planets from many science fiction works such as Star Trek, Project Hail Mary, Interstellar, Avatar, etc.

Version 1 adds 7 systems:
	The Sol system 
	Alpha Centauri system (Rigil Kentaurus) 
	Tau Ceti 
	40 Eridani A (Keid) 
	TRAPPIST-1 
	Gargantua (from interstellar) 
	Edmund (Orbiting Gargantua)
